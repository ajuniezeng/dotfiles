# Ajunie's Dotfiles

## Pre Requirements

- [Nerd Fonts](https://www.nerdfonts.com/): A font integrated with icons for development. I personally use [Iosevka](https://typeof.net/Iosevka/) patched by Nerd Fonts and [Source Han Sans HW](https://github.com/chrissimpkins/codeface/tree/master/cjk-fonts/source-han-sans-HW) for CJK characters.
- [Oh My Posh](https://ohmyposh.dev/): A prompt theme engine.
- [zoxide](https://github.com/ajeetdsouza/zoxide): A smarter cd command, written in Rust.
- [Eza](https://github.com/eza-community/eza): A `ls` replacement, written in Rust.
- [Helix](https://helix-editor.com/): A post-modern text editor.

## MacOS & Linux Requirements

- [Fish](https://fishshell.com/)
- [Fisher](https://github.com/jorgebucaran/fisher): Fish plugin manager.

## Windows PowerShell Requirements

- [Scoop](https://scoop.sh/): A package manager.
- [Git for Windows](https://github.com/git-for-windows/git)
